# Konsultasi Tubes Alpro

Repository ini berisi hasil konsultasi tugas besar algoritma pemrograman.

## Isi Utama

- Kode program C++ aplikasi CLI: `Konsultasi kelompok x/Kelompokx.cpp`
- Dokumen analisis kesesuaian terhadap ketentuan tugas: `Konsultasi kelompok x/analisax.md`

## Cara Kompilasi dan Menjalankan

```bash
g++ "Konsultasi kelompok x/Kelompokx.cpp" -std=c++17 -Wall -Wextra -o kelompokx
./kelompokx
```

## Catatan

Program dibuat dengan fokus pada implementasi dasar C++ berbasis menu terminal.
